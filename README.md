# EASESPACE - Your Personal Wellness Companion

![EASESPACE Logo](img/logo.png)

EASESPACE is a comprehensive wellness platform designed to help users achieve mental peace, reduce stress, and improve their overall well-being through guided meditation, breathing exercises, and daily wellness challenges.

## Features

### 1. Meditation Section
- **Guided Meditation Sessions**: Various meditation types including morning meditation, stress relief, and deep sleep
- **Ambient Sound Player**: 
  - High-quality ambient sounds (rain, ocean waves, forest, white noise)
  - Customizable volume control
  - Session timer with progress tracking
  - Play/pause and restart functionality

### 2. Breathing Exercises
- **Interactive Breathing Circle**: Visual guide for breathing exercises
- **Multiple Breathing Techniques**:
  - Box Breathing (4-4-4-4)
  - Deep Breathing
  - Relaxation Breathing
- **Customizable Duration**: Adjust session length to your preference
- **Visual Feedback**: Real-time animation for inhale/exhale phases

### 3. Daily Challenges
- **Wellness Challenges**: Daily tasks to improve mental and physical well-being
- **Progress Tracking**: Monitor your completion of challenges
- **Achievement System**: Earn badges and track your progress
- **Community Features**: Share and compare progress with other users

### 4. User Profile
- **Personal Dashboard**: Track your meditation and breathing exercise history
- **Statistics**: View your wellness journey progress
- **Customizable Settings**: Adjust app preferences to your needs

## Technical Stack

- **Frontend**:
  - HTML5
  - CSS3 with modern animations and transitions
  - JavaScript (ES6+)
  - Bootstrap 5.3.2
  - Font Awesome Icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/radiant-O/Calm.git
   ```

2. Open the project in your preferred code editor

3. Launch the application:
   - Open `index.html` in a modern web browser
   - For best experience, use Chrome, Firefox, or Safari

## Features in Detail

### Meditation Player
- **Sound Selection**: Choose from various ambient sounds
- **Timer**: Default 15-minute sessions with progress tracking
- **Volume Control**: Adjustable volume with mute option
- **Progress Tracking**: Visual progress bar with time display

### Breathing Exercise
- **Visual Guide**: Animated circle for breathing rhythm
- **Customizable**: Adjust breathing patterns and duration
- **Instructions**: Clear visual and textual guidance
- **Progress Tracking**: Session duration and pattern tracking

### Challenge System
- **Daily Tasks**: New wellness challenges every day
- **Categories**: Various wellness aspects (meditation, physical, mental)
- **Progress**: Visual progress indicators
- **Rewards**: Achievement system for completed challenges
